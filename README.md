# rust-web-server

从零构建的 Rust 量化回测系统，逐步演进为商用交易平台。

---

## 项目现状

### ✅ 已完成

- [x] Actix-Web HTTP 服务器框架
- [x] 事件驱动引擎 + 订单撮合逻辑
- [x] Strategy Trait 可插拔策略抽象 + DefaultStrategy
- [x] Candle/K线数据模型 + OHLCV 合法性校验
- [x] CSV 数据解析 (serde 中文别名) + `data_loader` 解耦
- [x] Portfolio/Position/Order/Audit 数据结构 + 真实持仓跟踪
- [x] 订单执行引擎 (限价单价格匹配 + 资金/仓位校验)
- [x] 佣金模型 (可配置费率 + 最低佣金)
- [x] 滑点模型 (方向偏置 + 正态分布随机噪声)
- [x] 净值曲线 (Equity Curve) — 逐 K 线记录
- [x] 最大回撤 (Max Drawdown) 计算
- [x] 测试 12 个，全部通过

### ❌ 关键缺失

- [ ] 印花税模型 (卖出千1)
- [ ] 尚无实际可盈利策略 (仅占位 DefaultStrategy)
- [ ] 无夏普比率/胜率/盈亏比等绩效指标
- [ ] 无可视化界面 (K线/净值曲线图)
